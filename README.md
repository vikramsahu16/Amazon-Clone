
# 🛒 Amazon Clone - HTML & CSS

A simple **Amazon website clone** built using **HTML & CSS**. This project focuses on replicating Amazon's homepage layout and styling to improve front-end development skills.

## 🎯 Features

✅ Fully responsive design using **CSS Flexbox & Grid**  
✅ Replicated **Amazon’s header, navigation bar, and product sections**  
✅ Optimized for different screen sizes  
✅ Styled with **pure CSS** (no frameworks)
